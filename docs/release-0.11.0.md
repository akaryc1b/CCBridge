# 0.11.0 · 任务中心与会话管理

- 页头统一任务中心：进行中、需处理、已结束与全部；宽窗双栏、小窗列表和详情切换，沿用亮暗主题。
- 全历史会话搜索：标题、用户输入和最终结果；中文子串、英文不分大小写，命中轮次定位与分页。
- 稳定首轮标题、人工重命名与 revision 冲突处理；归档、撤销、恢复，不删除结果或取消运行任务。
- 归档后的 Codex 续聊、状态和结果查询保持可用；App 恢复后再发送，保留全自动默认与原目录。
- 操作历史只保存安全元数据；旧连接或重启后的未结束操作先核实，不自动重放认证或 Git 写入。
- 新 Runner 支持不受最近100条限制的活动任务查询。旧 Runner 保留原接口，新会话功能提供更新入口。

现有应用内签名更新流程不变，不使用 Developer ID。ARM 独立先发布，Intel 完成后追加；发布不自动重启已运行的 App。
