# 0.10.2：SSH 与 Git 安全修复

- SSH库从russh 0.58.0升级至0.64.1，更新传递加密依赖；保留已保存主机指纹校验和密码认证，不自动接受新指纹。
- 新增错误长度X25519/零点握手回归：必须返回受控错误，不使客户端连接任务panic。
- 本机Git不用的stdout直接丢弃，stderr只保留64 KiB尾部；超时和继承管道的子进程按本次请求清理，不保留无界输出。
- CI增加三个正式目标依赖图的OSV安全检查、前端生产依赖审计和安全策略测试；未知公告、网络失败、过期豁免阻止发布。
- 安全文档更新为当前本机私有文件保存方式；全自动默认、账号授权和数据库权限保持原合同。
