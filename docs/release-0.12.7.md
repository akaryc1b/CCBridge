# 0.12.7 · Git 仓库总览

- 项目与文件内增加仓库列表，统一显示分支、上游、提交差异与本地缓存时间。选择仓库后，分支、更新和远端认证操作始终指向该仓库。
- 保留项目级“全部更新”和单仓库“更新仓库”。只更新当前跟踪分支，未提交修改、无上游、分叉或任务占用分别提示，不覆盖未提交修改。
- 新增“获取最新状态”，只获取远端引用，不更新工作文件；支持项目内全部仓库及单个远端，复用后台任务、真实进度与失败项重试。
- 支持选择上游分支，确认时核对当前提交、分支和目标提交。支持查看远端、修改地址、检测所选远端访问，以及直接进入现有 Codeup 认证窗口。
- 非 Git 项目显示中性空态，目录刷新同步刷新仓库列表；小窗口可滚动浏览完整仓库详情和文件列表。
- 远端地址不展示内嵌密码或令牌，保留 SSH 所需用户名；配置存在与仓库访问通过分开显示。长操作收起后从任务中心返回同一个操作，不重复执行。

沿用现有 SSH、Claude 登录、全自动默认、本机密码保存、任务占用保护及亮暗公共组件。不增加提交、暂存、代码差异或 PR 功能。
