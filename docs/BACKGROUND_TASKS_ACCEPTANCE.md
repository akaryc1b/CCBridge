## 使用方式

执行中的克隆、Git 更新、远端分支获取、Codeup 检测与认证同步可以点击“后台运行”收起。页头“后台任务”菜单保留进度、结果和返回入口。切页不取消请求，重开不重新派发；失败需要用户明确重试。

后台运行指收起弹窗和切换页面；仍需保持 App 运行。退出 App、SSH 中断或更新安装后的恢复不由本次功能保证，结果不确定时应先核实，不自动重发。

认证写入仍需当次明确确认；确认后执行过程不再占住授权弹窗。界面区分认证已保存、服务器已同步与仓库访问通过。

## 本轮修复

- 后台任务入口聚合，完成与失败结果不随收起消失。
- Git 更新、分支获取与克隆的目标目录固定，不随文件浏览改变。
- 后台完成只刷新仍在浏览的目标，不抢走当前文件位置。
- 认证弹窗关闭不使在途请求失效，重开不重置同一上下文的页签和输入；切换账号/连接仍隔离旧结果。
- 认证写入确认只授权当次请求，失败重试重新确认，不持久化确认标记。
- 分支失败详情不被重开时的自动读取抹掉。
- 项目页安装提示按纵向布局占据正常行，避免压缩文件区。
- 升级 `crypto-bigint 0.7.5 → 0.7.8`，修复依赖安全检查报告的 RUSTSEC-2026-0387。
