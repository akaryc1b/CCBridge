# 0.12.5 · 服务端自动检查与空闲更新

- SSH 连接或重连后自动检查服务端程序，保持连接时每30分钟检查一次。
- 服务端落后时等待本机操作、MCP等待与远端任务结束，空闲后自动更新到当前App配套版本；不降级、不更新Claude、不改登录和项目文件。
- 后台维护复用目录占用保护，安装前检查完整任务列表；失败显示原因并稍后重试，也可重新检查。首次缺少Runner或旧版不支持安全维护时保留人工安装入口。
- 工作台和服务器页显示检查、等待、更新、就绪或失败状态。
- 隔离SSH恢复后，实际stdio MCP连接查询、项目列表和任务列表已验证成功，不重放任务。

已完成隔离环境自动更新、80秒SSH无响应后自动重连及亮暗状态检查。真实锁屏MCP调用待补测，不把后台实现或隔离测试当作锁屏实测通过。本次仅发布安装包，现用App与Runner按用户要求不重启、不替换。
