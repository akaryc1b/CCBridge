# 0.10.0：远端模型选择与 Claude 用量

- 模型列表从当前 SSH 账号的远端 Claude Code 初始化接口获取，服务器默认模型和下一轮模型均改为下拉选择，移除手填入口；保留原 MCP 模型参数合同。
- 获取模型不发送用户提示、不启动模型推理；失败提供重试，不使用硬编码模型或历史会话冒充可选列表。
- 服务器页显示 Claude 最近上报的五小时、每周额度、恢复时间与上报时间；缺失、过期和读取失败分别显示，不伪造实时用量或0%。
- 用量读取当前账号的任务事件，不读取或导出认证信息，不为刷新额度另发模型请求。

- 工作台同步展示默认模型和Claude用量，两页共享数据；修复模型下拉在弹窗中不可见的问题。
- Mac窗口改为原生控制按钮与侧栏一体布局，移除顶部重复标题，保留窗口拖动与亮暗主题。
