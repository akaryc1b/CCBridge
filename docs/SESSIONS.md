# 查找分析与管理后台任务

## 找回一次分析

在「会话」搜索标题、用户输入或最终结果。中文按子串匹配，英文不区分大小写。搜索覆盖当前 SSH 账号全部可读取的历史，而不只是旧版列表的最近 100 个任务；不搜索中间消息、工具日志或仓库文件。

列表每页 30 个会话，点击「加载更多」继续。搜索片段显示命中轮次；点击片段可打开该轮。标题默认取首轮输入的第一个非空行，不随追问改变。在会话菜单可重命名；重名允许。另一窗口已修改时，读取最新状态，保留自己的输入，再决定是否保存。

「归档」将会话移出最近列表，通知中可撤销。在「已归档」查看或恢复。归档不取消任务、不删除结果，不影响 Codex 的状态查询、结果获取或续聊。App 中先恢复再续聊；Codex 续聊不自动取消归档。

## 查看后台执行

页头「任务中心」统一显示 Claude 轮次与 Git 更新、克隆、分支获取和服务器认证操作。「进行中」「需处理」「已结束」「全部」用于筛选；详情显示真实状态、实际模型、执行权限和已处理计数。没有依据时不显示百分比。

关闭任务中心不取消后台任务。打开原操作绑定具体操作 ID，不会重新派发。旧连接或重启后未结束的操作显示「结果待核实」；核实只读取当前状态，不重复写入、不把当前观察当作原操作已成功。历史克隆可打开目标目录检查，认证仍在原窗口检测并按当次确认写入。

任务中心的 Claude 活动查询不受旧 100 条列表上限影响；结束记录沿用最近任务窗口。操作历史只保存账号、ID、目录、状态、阶段、计数和时间等白名单字段，不保存密码、令牌、请求或完整结果。App 必须保持运行才能继续本机长操作；保存历史不等于提供可重放的队列。

## 离线与兼容

离线时显示同一进程已加载的会话，不能修改名称或归档；重连后刷新。切换服务器账号清空上一账号的详情和查询。

新功能需要带 `sessions_v1` 的 Runner。旧 Runner 可继续使用原任务列表与结果；更新 Runner 后启用搜索、命名、归档。旧记录缺少会话 ID 时作为独立旧记录展示，不合并为虚构会话。

查询采用账号私有的两分钟 ID 快照，最多保留 32 份；新活动显示「有更新」。修改名称、归档或快照过期时需要刷新。无法读取的记录明确显示「结果不完整」。扫描性能数据与原生 App 验收范围记录在版本验收报告中，不承诺所有服务器或任意大小结果都能即时搜索。

## 开发接口

新增 `session_list` / `session_search` / `session_turns` / `session_meta_get` / `session_meta_set` / `active_tasks`。会话正文仍通过原 `status/result` 按需读取；`session_turns` 返回每页 20 条轻量摘要。`list/status/result/cc_*` 原语义不变，旧 `list` 只追加 `session_meta`。

元数据写入仅限人工 App；远端 `sessions/<session_id>.json` 使用独立短锁、原子写和 `expected_revision`。不修改 worker 的 `task.json`。分页游标绑定查询条件、元数据世代和快照，不接受客户端指定别的账号。全自动默认及现有安全授权不变。
