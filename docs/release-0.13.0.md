# 0.13.0：会话工作区、状态提醒与 Claude 维护

## 会话与导航

- 保留常驻主菜单，支持图标模式；项目会话栏独立收起，记住用户选择。
- 会话列表采用紧凑树结构，固定搜索与同排筛选；保留搜索、重命名、归档恢复和项目管理。
- 显示运行、排队、待审批、完成等状态；结束结果区分已读/未读，续聊新结果重新提醒，与任务中心“全部已读”同步。
- 会话中浏览目录和预览文件，使用 @ 引用到草稿；复用原文件操作，不新增代码变更面板。

## 模型、思考与输出

- 根据远端模型能力提供思考强度下拉。同一会话发送前修改用于本轮，生成中修改用于下一轮；不修改远端全局配置。
- 输出流实时展示生成速度；有连续计数时使用计数，否则明确标“实时估算”。最终均速依据 CLI 上报计数和 API 耗时，工具执行与等待不沿用旧速度。
- 用量只展示当前账号实际返回的窗口，不固定补齐五小时统计。

## 安全修复

- SSH依赖russh升级至0.65.1，修复EXT_INFO无界分配、零最大包导致通道写入挂起等上游安全问题；保留密码认证与主机指纹确认。

## 项目保护与维护

- 全局禁止AI修改时，可由人在App为指定工作区开放写入；子目录继承，其他工作区仍受保护，MCP不能自行授权。此功能不是OS沙箱。
- 新增 Claude Code 检查更新和确认更新入口。检查不升级；确认后等待当前账号活动任务结束。仅支持账号私有native/npm安装；共享、Homebrew或未识别安装提示由原维护方处理，不提权。
- 更新完成重新读取实际版本和模型能力。旧Runner缺少新能力时保留原会话，新增控件禁用并提示。
