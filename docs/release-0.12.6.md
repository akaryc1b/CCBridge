# 0.12.6 · 分支选择与清理

- 分支选择改为可搜索列表，区分本地和远端；多仓库项目可直接选择仓库。
- 新建分支独立输入名称和起点；选择远端分支时优先切换已有跟踪分支。
- 新增本地分支删除、已合并分支批量清理；当前、默认、受保护、工作树或任务占用、未合并分支保留。
- 删除前重新核对分支提交及合并目标；不强制删除，不自动保存或丢弃未提交修改。
- 远端同名分支删除需额外勾选；复用认证，检查服务器分支提交未变化，不联动其他远端。
- 分支操作后立即刷新文件列表；失败可原位重新检查。
- 分支获取保留后台继续与任务中心恢复；排除 origin/HEAD 伪分支，失败原因只显示一次。

复用原有 SSH、认证、目录浏览、任务占用保护和公共组件。本次不改变全自动默认、Claude 登录、本机密码保存及自动连接。
