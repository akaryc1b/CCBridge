## 同工作区多会话并行分析

- 同一远端工作区可同时运行多个独立分析会话，沿用已有 Claude 登录；续聊保留原会话、目录和实际模型。
- 分析只开放读取和搜索；开发任务冲突时持久排队，显示占用来源、等待及暂停状态，可单独取消。
- 服务器新增“禁止 AI 修改项目文件”开关：限制 App/MCP 后续 AI 任务和 Codex Git 更新；既有开发不中断，排队开发暂停，关闭时确认恢复。
- App 人工 Git/文件操作保留，遇活动分析或开发显示具体占用，不强行修改。
- 修复连接后保护状态加载、会话及任务终态自动刷新、未知子进程占用保护。

分析保护是 Claude 工具权限策略，不是 OS 沙箱；管理员脚本及直接 SSH 不在此范围。受控分析需要支持相关参数的 Claude 2.1.308+ 2.1 系列，不兼容时明确拒绝，不降级为可写。

ARM 安装包先发布，Intel 完成后追加同一版本；原有本机密码保存、自动连接与全自动授权不变。

## SSH 断网恢复

- 自动连接开启时，断网后后台重试，网络恢复后复用本机密码重连。
- 手动断开后不自动重连；密码或指纹问题暂停重试并提示处理。
- 重连仅恢复连接与查询，不重复派发任务。
